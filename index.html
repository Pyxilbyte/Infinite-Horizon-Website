THE GAME

Survive beyond the horizon.

Infinite Horizon is an open-world survival game set in a procedurally generated world that keeps expanding as you explore.

Gather resources, craft tools, build structures, survive the night, and discover what lies beyond the next hill.

Current Version Alpha v0.1.0 Windows PC
